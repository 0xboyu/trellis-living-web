# Simple GitHub publication

These files are ready to upload without editing, installing anything, or obtaining a token.

1. Sign in at https://github.com/new. Choose **trellis-living-web** as the repository name and **Public** as visibility. Select **Create repository**. Do not initialize a README; one is included here.
2. In the empty repository, choose **uploading an existing file**. Drag the contents of this prepared folder into the upload area: root `index.html`, `README.md`, the other Markdown files, and the `source` folder. Do not upload the ZIP or the outer folder itself. The root `index.html` must be visible at the top level. `.nojekyll` is included but optional for this entirely inline HTML app if your file picker hides it.
3. Choose **Commit changes**. This creates the working repository; copy its actual URL from the browser.
4. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**. If GitHub created a different default branch, choose that branch instead.
5. Wait for Pages to finish. Copy the live URL GitHub displays; do not assume it is deployed until that address loads. Open it and exercise Enterprise Buyer → Discount Campaign (price still $49) → Approve ($29) → Rollback ($49, v4).
