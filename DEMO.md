# 90-second presentation

Before starting: open `index.html`, use a 1440 × 900 display at 100% zoom, and choose **Reset demo → Reset & clear history**. Keep both panels visible. Only the right panel needs scrolling to reveal the review actions and ledger details.

**0–15 seconds · Set the problem**

“The living web can adapt itself to every visitor. But if a website can rewrite itself, who supervises the changes? Trellis makes every modification visible, risk-gated, and reversible. On the left is RelayOps, a fictional AI SaaS. On the right is its supervision layer.”

**15–35 seconds · Click Enterprise Buyer**

“An enterprise buyer arrives. The headline and call to action change, governance moves to the front, and the assurance section moves above the features. Those are real changes to a structured PageSpec. Trellis computes the diff, checks the fields, and safely publishes version two.”

**35–55 seconds · Click Discount Campaign; reveal the review card**

“Now a campaign proposes a price drop from forty-nine dollars to twenty-nine, together with new copy. Pricing is protected. Trellis holds the entire proposal. Here are the actual before and after values. The live price is still forty-nine. Nothing changes until a supervisor decides.”

**55–68 seconds · Click Approve proposal**

“I approve it. The price and campaign copy update together in version three, and that approval gets its own ledger event. A rejection would have kept the page unchanged. An old approval cannot overwrite a newer version.”

**68–82 seconds · Click Rollback**

“Now I roll back. The previous approved page returns, including the forty-nine-dollar price. This creates version four. It preserves the complete history rather than erasing what happened.”

**82–90 seconds · Close**

“Codex authored these scenarios during development. Runtime replay is deterministic; the policy, diffs, and versioning are real. Trellis gives a self-rewriting web the supervision it needs.”

# Submission copy

**Name:** Trellis — The Supervision Layer for the Living Web

**One-liner:** Visible changes, deterministic risk gates, human approval, and reversible versions for self-rewriting websites.

**Description:** Trellis pairs a living SaaS landing page with a supervision dashboard. AI-authored visitor scenarios propose JSON PageSpec changes. An executable diff and policy pipeline auto-applies safe presentation changes and atomically holds protected changes such as pricing, terms, claims, guarantees, destination URLs, and section deletion. Supervisors can approve or reject proposals, while version checks prevent stale approvals. Rollback creates a new version and preserves the full ledger. Built with dependency-free HTML, CSS, and vanilla JavaScript; runs offline from index.html and unchanged on GitHub Pages. No runtime LLM calls.

**Built with:** Codex Desktop; HTML; CSS; vanilla JavaScript; Node built-in assertion tests. Chromium/Playwright used only for development verification, not as application dependencies.
